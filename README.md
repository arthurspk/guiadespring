## :dart: O guia para alavancar a sua carreira

> Spring é o framework mais usado para construir aplicações Java no mercado — do backend de bancos e fintechs a e-commerces e sistemas de governo. Com o Spring Boot, você monta uma API REST funcional em minutos, e o ecossistema (Spring Data, Spring Security, Spring Cloud, Spring AI) cobre praticamente qualquer problema de backend que você vá encontrar no dia a dia. Este guia reúne documentação oficial, cursos gratuitos e pagos em português e inglês, livros, canais no YouTube, ferramentas, projetos práticos e um capítulo dedicado a usar IA na prática com Spring — tudo verificado e organizado para quem já sabe Java e quer entrar (ou evoluir) no backend corporativo.

## 🤖 IA na prática

Spring é hoje um dos frameworks Java com integração mais madura com IA: o próprio time do Spring mantém o **Spring AI**, um projeto oficial que traz para o ecossistema Spring os mesmos padrões (`@Autowired`, auto-configuração, starters) já conhecidos, agora aplicados a chat com LLMs, embeddings, RAG e agentes.

**Para aprender**
- Peça para uma IA **explicar uma stack trace de exception do Spring** (ex.: `NoSuchBeanDefinitionException`, `LazyInitializationException`) linha a linha e sugerir a causa mais provável antes de sair copiando a primeira solução do Stack Overflow.
- Peça para **gerar um projeto Spring Boot mínimo** com uma entidade, repositório, controller REST e teste, e depois peça para explicar o papel de cada anotação (`@RestController`, `@Service`, `@Entity`, `@Transactional`).
- Cole um `application.properties` seu e peça para a IA explicar o que cada propriedade faz — bom exercício para entender configuração sem decorar.
- Peça exercícios com gabarito sobre o assunto que estiver estudando (injeção de dependência, Spring Data JPA, Spring Security).

**Para trabalhar**
- Use [GitHub Copilot](https://github.com/features/copilot), [Claude Code](https://code.claude.com/docs/en/overview) ou o [assistente de IA do IntelliJ IDEA](https://www.jetbrains.com/ai/) para gerar DTOs, mappers, testes com JUnit/Mockito e documentação de endpoints — sempre revisando o que foi gerado.
- Use o [Spring AI](https://spring.io/projects/spring-ai) para integrar sua própria aplicação Spring Boot a modelos de linguagem: o [`ChatClient`](https://docs.spring.io/spring-ai/reference/api/chatclient.html) padroniza chamadas a diferentes provedores (OpenAI, Anthropic, Ollama) com a mesma API fluente do Spring.
- O Spring AI também expõe suporte oficial ao [Model Context Protocol (MCP)](https://docs.spring.io/spring-ai/reference/api/mcp/mcp-overview.html), permitindo que sua aplicação Spring exponha ou consuma ferramentas para agentes de IA.
- Depois de aceitar qualquer sugestão de código, rode os testes (`mvn test` / `gradle test`) e confira se os beans sobem corretamente — o Spring falha rápido (fail-fast) na inicialização quando algo está mal configurado, o que ajuda a pegar erros gerados por IA.

**Limites e boas práticas**
- IA erra e inventa nomes de métodos e anotações, principalmente em módulos que mudam entre versões (Spring Security 5→6, javax→jakarta). Confirme sempre na [documentação oficial](https://docs.spring.io/spring-boot/index.html).
- Não cole credenciais, strings de conexão de produção ou dados de clientes em ferramentas de IA sem a política de segurança da sua empresa.
- Entenda o que você aceita: em entrevista técnica e em produção, o código — e os bugs — são seus.

- [Spring AI — página do projeto](https://spring.io/projects/spring-ai) — Projeto oficial do time do Spring para integrar aplicações Java a modelos de IA.
- [Spring AI — documentação de referência](https://docs.spring.io/spring-ai/reference/index.html) — Documentação oficial completa: chat, embeddings, RAG, function calling e MCP.
- [spring-projects/spring-ai (GitHub)](https://github.com/spring-projects/spring-ai) — Repositório oficial do código-fonte do Spring AI.
